# Projektvorgaben

## Automatische lokale Commits

Ausdrückliche Nutzeranweisung vom 2026-10-27:

- Nach jeder abgeschlossenen, vom Nutzer beauftragten Änderung automatisch einen lokalen Git-Commit erstellen, ohne erneut nachzufragen.
- Vor dem Commit die Änderungen prüfen und angemessene Prüfungen durchführen.
- Nur die zum Auftrag gehörenden Änderungen committen; fremde oder unklare Änderungen nicht ungeprüft aufnehmen.
- Eine kurze, aussagekräftige Commit-Nachricht verwenden.
- Nicht automatisch auf GitHub pushen. Pushes benötigen einen ausdrücklichen Nutzerauftrag.
- Keine leeren Commits erstellen. Fehler bei Prüfung oder Commit offen melden.
